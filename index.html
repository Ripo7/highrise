    How to play

    Build it. Ride it.

    Design a slope section by section, then make it yours: shape the snow, add jumps and trees, put the start wherever you like, and ride it. Jump between riding and building whenever you want: the run waits for you.

    1. Design the slope Stack sections down the mountain, each with its pitch and its length, and pick how wide it is. Change it any time with the Slope button.
    2. Select, then shape Click or drag on the snow to select hexagon tiles, then act on them: raise, lower, flatten, smooth, steepen; a jump, a drop, rocks, a gate; trees, a clearing, powder, ice; copy, paste, rotate, erase. Tap again for more. Tiles side by side melt into one shape. Tap or drag on the snow to select hexagon tiles, then act on them: raise, lower, flatten, smooth, steepen; a jump, a drop, rocks, a gate; trees, a clearing, powder, ice; copy, paste, rotate, erase. Tap again for more. Tiles side by side melt into one shape.
    3. Start anywhere Pick Start and click the snow (or drag the gate): the run starts there, down the fall line. Pick Start and tap the snow (or drag the gate): the run starts there, down the fall line.
    4. Ride ← → carve (all the way: skid it round), ↓ hockey stop, ↑ tuck (or push with the poles on the flat). Hold Space and release to jump; in the air ← → spin, ↑ ↓ flip. Left thumb: carve (all the way to skid it round), down for a hockey stop, up to tuck. Right thumb: hold Jump, release to pop. In the air, slide to spin, drag up or down to flip.
    5. Build, ride on Esc pauses the run to build; Ride on (Space) picks up where you were, at the same speed. From the start (Shift+Space) goes back to the gate. Build pauses the run; Ride on picks up where you were, at the same speed. From the start goes back to the gate.
    6. Set a course Put gates on the tiles (Features ▸ Gate): a run only counts through every gate. Then beat your best time, and your best score.
    7. Learn with the tutorial Thirteen short levels, one action at a time. Any time from the ••• menu.
